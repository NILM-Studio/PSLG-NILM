# 真实完整周期补充对照：先分清原数据差异与拼接后的变化

本轮按用户要求，只给已经完成的 `ukdale_wm_composition_prechange_20260917` 增加真实周期对照，再根据结果决定修改。**不重跑原拼接入口，不改时期、划分、分类筛选、预算、五种方法或参数，不训练生成模型或NILM。**

## 为什么补这轮

回传的时期内实验有419个最终训练周期、63个验证周期、127个测试周期；107组完成案例来自30个不同锚点，包含535条方法输出。其中18组案例没有同Class/Mode验证参考，另有28组仅有1个同组验证周期，不能当作充分验证。

初步只读复核发现：同组真实训练与验证之间本来就存在能量/时长差异。仅看生成波形到验证集的距离，不能把全部差异归因于拼接。5%预算下18组完成案例的转移支持均为none，不能据此宣称已学到低预算转移规律。本轮保留这些事实，不降低门槛或换划分来改善分数。

## 补充哪些对照

所有对照都按原seed、预算、Class/Mode及原转移支持状态分层，使用同组真实验证周期作为参考。

| 对照 | 来源与数量 | 用途与限制 |
| --- | --- | --- |
| `full_train_context` | 同Class/Mode的全部真实训练周期 | 看训练→验证的背景差距；数量不同，不作公平排名 |
| `budget_pool_context` | 原预算内同Class/Mode的全部真实周期 | 看预算取样后的背景差距；数量不同，不作公平排名 |
| `original_anchors` | 与本层完成生成案例一一对应的原始真实锚点 | 比较原模板周期与拼接后周期的变化 |
| `matched_budget_real` | 同预算、同Class/Mode内，等量抽取完整真实周期 | 默认100次抽样，量与本层生成案例一致；每次无放回，不同次可重叠 |

等量抽样允许抽到原锚点，也允许与原供体池重叠，不把它冒充独立新数据。抽样不参考验证指标，也不挑“表现最好”的子集；全部抽样ID保存。100次是**真实周期抽样次数，不是100次生成或独立实验种子**。P10/P50/P90只是抽样波动，不是置信区间或显著性。

`full/partial/none`描述原转移模型支持度，不是新真实周期对照的质量等级；真实池不按生成方法得分再次筛选。

比较指标：

- 完整周期：时长(s)、能量(Wh)、均值(W)、峰值(W)。直接从原始波形按原拼接采样间隔重算，避免混用近似采样率与6秒间隔。
- 状态边界：按有向状态对分别计算带符号跳变(W)、左右块内局部斜率(W/s)，沿用既有测量定义，不把真实物理跃迁视为必须消除的错误。
- Wasserstein-1距离保留物理单位。相对锚点及等量真实抽样中位数的距离差，仅作诊断对照，不是因果分解或显著改进结论。

等量周期不保证等量状态边界，报告分别保存边界数和不同周期数。缺少参考或源观测时为null/NA，不填0；生成或验证不同周期不足3个时标为low_support，达到3个也不自动代表统计充分。各方法固定原锚点的时长，时长行不是方法间的独立证据。

## 拿到结果后再决定改什么

1. 若真实训练/真实等量对照本身已与验证差异较大，先定位时期内漂移、模式覆盖与模板取样问题，不把它全部记为拼接错误，也不按结果重新挑时间边界。
2. 若生成相对原锚点及等量真实周期在能量/峰值上额外偏离，再定位供体选择与时长适配；是否修改要看逐组证据。
3. 若周期统计尚可，但特定有向状态对的跳变/斜率额外失真，再考虑对应边界约束，不能用所有边界跳变越小越好代替真实参考。
4. 对样本不足或转移无支持的组保留限制，先不据此排序算法；也不启动多种子大实验或NILM训练。

这轮是诊断性补充对照，不是论文最终效果实验。继承的表示学习拟合范围未得到训练侧认证，完整端到端无泄漏主张仍不能成立。
