# NILM 基元状态定义与使用边界

本文固定当前实验中“基元状态（primitive state）”的含义，避免把自动聚类标签误写成功能语义或物理真状态。适用范围是当前 UK-DALE 洗衣机实验、6 秒采样、H1 源训练和 H5 开发配置；不同电器、住宅、数据集或发现配置必须使用独立字典，不能直接复用本字典的簇号。

## 1. 一句话定义

基元状态是：**在目标电器分表功率上，先按可靠活动区间切出局部片段，再依据片段功率形态进行聚类，并把聚类类型投影回活动内部观测点后得到的离散伪标签。**

它是训练期从分表派生的辅助监督，不是部署时需要输入的传感器，也不是人工标注的“加热、脱水、排水”等功能名称。

用符号表示，给定目标电器分表 (y_t)：

\[
\text{activity}\rightarrow\text{segment}\rightarrow\text{feature}\rightarrow\text{cluster}\rightarrow\text{temporal merge}
\rightarrow z_t.
\]

其中 (z_t) 是逐点状态标签，状态字典、参数和来源哈希随实验冻结。NILM 推理时只输入总表 (x_t)，模型预测功率和状态概率；真实分表、真实活动边界和真实状态标签不能作为输入。

## 2. 四个容易混淆的概念

| 名称 | 当前定义 | 是否等于功能语义 |
| --- | --- | --- |
| 基元实例 | 一个活动内部、由分段规则得到的局部功率片段 | 否 |
| 基元类型 | 对多个片段特征聚类后得到的类别，当前主设置为 K=5 | 否；编号只是字典内 ID |
| 状态块 | 聚类后经过时间合并形成的连续块，具有起止时间、类别和成员片段 | 否；边界可能受观测和活动截断影响 |
| 功能状态/程序阶段 | 有外部含义的操作阶段，例如加热或排水 | 当前没有独立语义标签验证 |

一个洗衣程序可以包含多个基元类型，同一类型也可能在不同程序中重复出现。不同字典中的“类别 1”没有跨数据集、跨电器或跨训练折的共同含义。

## 3. 当前标签生成链

当前正式源侧发现链为：

1. 使用目标分表和固定原活动规则提取活动区间；活动区间外为 OFF 或上下文，不自动当作某个基元类型。
2. 在真实观测支持上运行 PrimGLR 进行局部分段。
3. 使用 DeTSEC-PC / S3 特征表示片段；当前形状特征包括均值、标准差、Q90−Q10、端点变化率、中位相邻变化率、观测跨度的对数及相邻观测缺失指示。
4. 在 H1 源训练数据上做标准化和 K-means，主设置 K=5、`random_state=42`、`n_init=30`。
5. 按原方法的时间合并规则保存状态块和状态序列，再将结果投影到用于 NILM 的逐点标签出口。

状态块的“持续时间”定义为该块首个和末个可靠观测点之间的时间跨度。它不是完整状态持续时间：活动起止、记录边界、窗口截断和缺测都可能使块不完整。

## 4. 标签编号与当前分布

NILM 标签包含一个 OFF 类和五个 ON 基元类型。OFF 的含义是当前活动/状态支持之外的类别，不表示每个点的真实物理功率严格为零；回归目标仍由独立的目标观测掩码决定。

在当前 H1 源训练记录 `ukdale_h1_washing_machine` 中，逐点标签计数为：

| 标签 | 当前解释 | 点数 |
| ---: | --- | ---: |
| 0 | OFF / 非基元支持 | 935,540 |
| 1–5 | 五个自动聚类得到的 ON 基元类型 | 29,687 / 2,741 / 7,572 / 8,792 / 583 |

五个 ON 类型分别出现在 65、46、58、48、23 个独立活动中，满足本轮“每类至少出现于 5 个活动”的源侧支持条件。活动点总数为 49,375，状态监督覆盖率为 100%；其中 8,898 个低功率活动点仍保留在活动和状态监督中。

聚类中心的功率尺度可用于审计，但不能用来命名状态。当前记录的中心功率约为 40、1,990、250、3,419 和 1,780 W；这些数值是标准化特征聚类和样本分布的结果，不是五种已验证的物理工作模式。

## 5. 观测、活动和缺测规则

当前标签接口把三类信息分开保存：

```text
目标功率 y_t：只在真实目标观测点参与回归损失
活动参考 a_t：由原活动规则得到，用于 ON/OFF 及活动头监督
基元标签 z_t：只在可靠活动和真实状态支持内参与状态损失
```

具体规则如下：

- 核心活动内部即使功率短暂低于原阈值，也保留其活动和基元标签；这是一致的活动接口规则，不是重新运行瞬时阈值检测。
- 活动上下文不扩大核心活动范围，不能因为上下文有功率就赋予基元类别。
- 缺测、没有状态覆盖或存在冲突的点使用 `ignore_index=-100`，不参与基元或活动辅助损失。
- 缺测目标的零占位不表示 OFF；目标功率回归必须由 `observed` 掩码控制。
- 不跨活动、不跨真实时间缺口拼接片段或状态序列。
- 训练、验证和测试阶段的模型输入只有总表及可用时间信息；真实状态只可用于训练监督和离线评分。

## 6. 状态序列的含义和当前限制

状态序列按活动内部的真实时间排序，记录类别、起止、块 ID、成员片段、持续时间和截断标记。它可以描述“某个活动中出现了哪些自动聚类状态以及它们的时间排列”，但当前不能直接被描述为完整洗衣程序。

本轮源侧质量证据包括 103 个局部边界在 ±12 秒范围内完全观测，34 个活动至少包含两个这样的边界；完整观测状态块数量仍为 0。人工遮盖审计显示在设定的局部缺口扰动下，标签恢复一致率为 100%，边界 F1 为 0.9865–0.9978。该审计只说明指定扰动下的稳定性，不提供真实缺测处的状态真值，也不证明状态具有功能语义。

当前 NILM 序列头接收模型预测的状态概率，而不是把真实状态输入模型：

\[
\hat p_t=\operatorname{softmax}(\text{state\_logits}_t),
\qquad
\hat a_{1:T}=\operatorname{GRU}(\hat p_{1:T}).
\]

GRU 在每个窗口重新初始化，不跨随机训练窗口传递隐藏状态。第一版功率头仍直接读取共享特征，状态概率和 GRU 输出只通过辅助损失产生梯度影响；因此当前实现没有强制“某一状态必须对应某种功率”，也没有显式的转移、持续时间或程序约束。

## 7. 与对照标签的关系

| 标签组 | 定义 | 用途 |
| --- | --- | --- |
| O | 原活动区间的 ON/OFF | 检查活动监督本身是否有效 |
| B | 活动内逐点功率 K-means 等级 | 简单幅值状态对照 |
| BP | 在 P 的最终状态块内计算观测功率均值，再聚类 | 给定 P 边界后的均值对照 |
| S | 同一最终块上的简单形状统计聚类 | 检查是否只需低成本形状特征 |
| P | DeTSEC-PC/S3 特征聚类得到的五类基元 | 当前拟检验的基元监督 |

因此，P 优于 R 只能说明辅助状态监督可能有下游价值；P 还必须稳定优于 B、BP、S，才能支持“深度基元表示提供超越简单幅值或形状的额外信息”。P＋GRU 还必须优于 P＋直接活动头、P＋逐点头、BP＋GRU、O＋GRU 和 H＋GRU，才能将收益归因于基元概率的时序组织。

## 8. 当前表述边界

可以说：

- “H1 分表上的自动发现局部功率状态”；
- “K=5 的数据驱动伪标签”；
- “训练期基元状态辅助监督”；
- “状态块的时间顺序和持续时间统计”。

当前不能说：

- “五种真实物理状态”或“识别出加热、脱水、排水”；
- “每个状态具有跨住宅、跨电器的固定含义”；
- “基元标签不需要分表监督”；
- “状态序列已经表示完整程序或因果实时过程”；
- “标签覆盖率 100% 等于状态准确率 100%”。
